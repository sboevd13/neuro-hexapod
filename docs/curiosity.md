# Интерес к предметам: обнаружение, безопасное приближение и память

Экспериментальный модуль `autonomy/curiosity.py` не затрагивает V5 или PPO,
а дополняет навигацию при `--curiosity`. Пока без реальной камеры: информация
о предметах поступает из 23 идеализированных дальномерных лучей на плоскости.
Положение робота берётся из MuJoCo без шума (это не SLAM).

## Что делает

1. Находит группы близких отражений дальномера, отбрасывает точки на границе комнаты.
2. Сопоставляет новые наблюдения с прошлой пространственной гипотезой объекта.
   Не использует скрытые ID или координаты геометрии MuJoCo для решения.
3. Выбирает ещё не исследованный объект с учётом его новизны, прошлых наград
   и риска столкновений. Путь к точке осмотра строит **в известных свободных
   ячейках** карты с радиусом безопасности исходного планировщика.
4. Подходит только на безопасную дистанцию, разворачивается лицом к объекту,
   фиксирует успешный осмотр и снижает его новизну (*привыкание*).
5. При столкновении отдаёт управление существующей процедуре восстановления,
   увеличивает риск объекта и прекращает попытку.
6. Сохраняет `objects.json`: координатные гипотезы, новизну, число осмотров,
   награды, столкновения и показатели эксперимента.

После достижения цели или отсутствия подходящих объектов снова работает
обычное исследование по фронтирам. Цель не предполагает физического контакта:
для этого роботу нужны дополнительные датчики и отдельная стратегия касания.

## Запуск

```bash
python explore_laptop.py --reference --curiosity --seconds 90 --seed 7 \
  --output runs/curiosity/demo --view
```

Сравнение базового алгоритма и режима исследования объектов:

```bash
python benchmark_autonomy.py --mode baseline --seconds 60 \
  --seeds 7 11 23 31 47 59 --output runs/curiosity/benchmark
python benchmark_autonomy.py --mode curiosity --seconds 60 \
  --seeds 7 11 23 31 47 59 --output runs/curiosity/benchmark
```

Чтобы сохранить память предметов и продолжить ту **же** комнату (тот же seed
и неизменная процедура генерации):

```bash
python explore_laptop.py --reference --curiosity --seconds 90 --seed 7 \
  --output runs/curiosity/demo --continue-map --continue-objects --view
```

Уже осмотренные объекты при повторном запуске не преследуются. Число объектов —
**гипотезы**, а не достоверное число реальных предметов: один предмет может
дать несколько групп отражений, два соседних могут слиться. Приближение к
объекту не равно пониманию его назначения, способности им манипулировать или
универсальному переносу навыков. `objects.json` хранит опыт наблюдения, но
не является самостоятельно обученной нейросетью распознавания предметов.

## Ограничения

Проверки используют ровную поверхность, неподвижные коробки и идеальный
дальномер. Недоступны цвет/форма/смысл объекта, оценка его подвижности,
реальное зрение, обратная связь всех 18 суставов, самостоятельная зарядка.
Все результаты в MuJoCo. Контакт с неизвестным объектом не является целью.
