# Обучаемый поведенческий уровень: локальная реакция на препятствия

Этот модуль — первый **обученный нейросетевой** механизм выбора высокоуровневого
действия. Он дополняет, а не заменяет глобальную навигацию, V5 и residual PPO.

## Что реально реализовано

Маленькая сеть 12→32→32→3 получает девять нормированных дальномерных лучей,
направление на текущую путевую точку (sin/cos) и расстояние до неё. Её три
выхода оценивают краткосрочную полезность действий: **вперёд, повернуть налево,
повернуть направо**. Карта неизвестной комнаты по-прежнему хранится отдельно.

Сеть обучена оценивать награду, вычисленную **после виртуального действия** в
случайной 2D-сцене. Награда учитывает продвижение к цели, поворот к цели и
столкновение корпуса с препятствием. Для обучения поочерёдно проверяются все
три действия в симуляторе; при запуске MuJoCo сеть видит только лучи и waypoint.
Это **контекстный однокроковый выбор действия**, а не долгосрочный PPO/DQN,
не непрерывное самообучение на роботе и не полноценная система восприятия.

В MuJoCo модель вызывается только рядом с препятствием. Безопасный фронтирный
планировщик остаётся ответственным за маршрут. Аппаратное ограничение:
при измеренном расстоянии меньше 0.37 м команда «вперёд» запрещена независимо
от выхода сети. При чрезмерно длительных повторных поворотах используется
базовый планировщик. Модель использует симулированную глубину и истинную позу
MuJoCo — ни камера, ни визуальная локализация ещё не подключены.

## Обучение и проверка

```bash
python -m pip install -r requirements-laptop.txt
python -m unittest discover -s tests -p 'test_behavior.py' -v
python train_behavior.py --train-samples 12000 --test-samples 3000 --epochs 32
```

В `models/behavior_v1.json` уже сохранён результат этого обучения, чтобы можно
было запускать демонстрацию без повторного обучения. `runs/behavior_validation.json`
содержит оценку на отдельном seed с новыми сценами.

```bash
# Условия одинаковые, карта создаётся заново для каждой сцены
python benchmark_autonomy.py --mode baseline --seconds 60 --seeds 7 11 23 31 47 59
python benchmark_autonomy.py --mode learned --behavior-model models/behavior_v1.json --seconds 60 --seeds 7 11 23 31 47 59
```

Визуальная демонстрация:

```bash
python explore_laptop.py --reference --seconds 90 --seed 7 --behavior-model models/behavior_v1.json --view
```

С существующей нейросетевой **двигательной** политикой V3:

```bash
python explore_laptop.py --checkpoint checkpoints/laptop_v3/best.npz --seconds 90 --seed 7 --behavior-model models/behavior_v1.json --view
```

Нейросеть поведения не изменяет и не переобучает 18 суставных выходов PPO.
Метрика `neural_decisions` означает вызовы новой сети, а `neural_overrides` —
случаи, когда итоговая команда отличается от стандартного планировщика.

## Ограничения

- Доля исследованной карты — доля ячеек с измерениями, а не пройденная площадь.
- Ошибка на тестовых 2D-состояниях не означает гарантии в MuJoCo; нужна отдельная
  сравнительная физическая проверка и нельзя судить только по loss.
- Для полноценного «искусственного животного» понадобятся последовательное RL,
  память о причинах событий, самостоятельное накопление опыта, зрение, акустика,
  оценка положения и аппаратные ограничения безопасности.
- Не запускайте автономный режим на Arduino/MG996R до появления аппаратной
  обратной связи, ограничений скорости/мощности и аварийного останова.
