# Обучение на физическом взаимодействии с разнообразными объектами

Исследовательский прототип, полностью в MuJoCo. Двухэтапный опыт:

1. V5 гексапод обнаруживает поверхность одним идеализированным 23-лучевым дальномером и идёт к ней (MuJoCo предоставляет точную позу).
2. После фактического контакта выполняет короткий пробный толчок и измеряет смещение **лучами**, без знания массы, трения и подвижности объекта.
3. Небольшая MLP предсказывает, достигнет ли суммарное смещение предмета после продолжения толчка порога 5 см.
4. Для независимой проверки физический движок выполняет второй толчок **для каждого** тестового объекта, даже если модель предлагала бы его пропустить. Это контролируемая проверка прогноза, а не реальное безопасное развёртывание.
5. Отдельно считаются Brier score, кросс-энтропия и точность на новых объектах. Сравнение — постоянная вероятность, равная доле положительных примеров только в тренировочной выборке.

Случайные сцены: размер, масса и трение независимо выбираются из непрерывных диапазонов; 30% объектов закреплены. Алгоритму не передаются скрытые физические параметры. Из-за слабой наблюдаемости не гарантируется, что он научится предсказывать всё по одному пробному касанию.

Запуск:

```bash
python affordance_rollouts.py --output runs/embodied
```

Стандартно выполняются 32 тренировочные и 16 тестовых физических сцены. Обученная модель и измерения находятся в каталоге `runs/embodied/`. Модель сохраняется в JSON. Не смешивайте обучающие и тестовые seed.

Важно: это адаптация **прогноза результатов толчка**, а не обучение моторного навыка и не обучение распознаванию материалов камерой. Моторика остаётся V5 reference. Один сценарий — один независимый физический эпизод для воспроизводимого обучения. Цель автономного непрерывного цикла с несколькими объектами в одной комнате проверяется отдельным сценарием.

Порог 5 см выбран как инженерный критерий заметного итогового смещения.
Начальные прогоны с прогнозом только добавочного движения дали результат хуже константного базового прогноза. Новая постановка оценивается на других случайных seed и не должна подбираться по той же тестовой выборке.

## Непрерывный сценарий с тремя предметами

В отдельном полном запуске `autonomous_world.py` работает **один** MuJoCo-мир со всеми тремя предметами одновременно. Робот видит мир через виртуальные лучи, постепенно строит карту, выделяет неизвестные объекты, выбирает цели осмотра, осторожно пытается добраться до них и после контакта может выполнить двухэтапный толчок. Результаты записываются в общий журнал, по которому можно при следующем запуске обновлять прогнозную сеть.

```bash
python autonomous_world.py --seed 7 --seconds 90 \
  --model runs/embodied/model.json \
  --experience runs/embodied/train/episodes.json \
  --output runs/integrated/demo --view
```

Это **отдельный экспериментальный прототип**, а не единый робот-продукт: точные координаты из симулятора используются для локализации, глубина сгенерирована по геометрии MuJoCo, обнаружение объектов по редким лучам может объединять несколько объектов, а эксперименты содержат только простые толчки, не захваты манипулятором. `report.json` честно показывает, сколько целей действительно замечено, сколько контактов и сколько обучающих исходов произошло. Если не удалось добраться до предмета, это не учитывается как успешное обучение.

Для обновления нейросети внутри непрерывной комнаты укажите `--experience` с ранее собранными физическими пробами. При каждом новом измеренном исходе модель дообучается вместе с предыдущими примерами, а число реальных обновлений фиксируется как `online_network_updates`. Без исходной выборки модель сначала только собирает наблюдения; она не обучается на одном-двух примерах из пустой памяти.

## Проверенные результаты и готовый запуск

GitHub Actions: [успешный полный запуск](https://github.com/sboevd13/neuro-hexapod/actions/runs/44551037040).

На **16 новых объектах**, после обучения на 32 других, Brier score составляет 0,22636 против 0,24316 у прогноза постоянной частотой; точность классификации у обоих 62,5%. Преимущество по вероятностной калибровке небольшое и **не доказывает общую интеллектуальность или устойчивую переносимость**.

В трёх отдельных непрерывных виртуальных комнатах, по 90 секунд каждая, получено: 9 обнаруженных гипотез об объектах, 5 осмотров, 5 робот–объектных физических контактов, 2 полных толчка, 3 решения прекратить после короткой проверки, 2 новых обучающих исхода, **2 обновления нейросети прямо во время работы** и 0 падений. Средняя исследованная часть карты около 74,98%. Эти числа нельзя сопоставлять напрямую с контрольными испытаниями обычной навигации на других планировках.

Готовые сохранённые файлы:
- `models/affordance_outcome_experimental.json` — обученные веса;
- `models/affordance_training_experiences.json` — только измеренные входы и метки, **без скрытой физики**;
- `validation/embodied_learning_v1.json` — метрики и ограничения.

Быстрый демонстрационный запуск с готовой моделью **и** ранее собранными примерами для онлайн-дообучения:

```bash
python autonomous_world.py --seed 7 --seconds 90 \
  --model models/affordance_outcome_experimental.json \
  --experience models/affordance_training_experiences.json \
  --output runs/world_demo --view
```

После завершения в `runs/world_demo` сохраняются `report.json`, `map.json`, `objects.json`, `experiences.json`, `predictor.json`. Отдельная команда `affordance_rollouts.py` позволяет с нуля переобучить модель по новым seed.

**Ограничение:** пока это объединение уровней алгоритмического исследования и нейросетевого прогноза последствий, но не единая обучаемая с нуля политика действий. Новая версия ещё не управляла физическими сервоприводами. МуJoCo-толчки намеренно ограничены в симуляции; не переносить эти команды на настоящее устройство без проверки силы и остановки.
