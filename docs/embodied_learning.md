# Обучение на физическом взаимодействии с разнообразными объектами

Исследовательский прототип, полностью в MuJoCo. Двухэтапный опыт:

1. V5 гексапод обнаруживает поверхность одним идеализированным 23-лучевым дальномером и идёт к ней (MuJoCo предоставляет точную позу).
2. После фактического контакта выполняет короткий пробный толчок и измеряет смещение **лучами**, без знания массы, трения и подвижности объекта.
3. Небольшая MLP предсказывает, достигнет ли суммарное смещение предмета после продолжения толчка порога 5 см.
4. Для независимой проверки физический движок выполняет второй толчок **для каждого** тестового объекта, даже если модель предлагала бы его пропустить. Это контролируемая проверка прогноза, а не реальное безопасное развёртывание.
5. Отдельно считаются Brier score, кросс-энтропия и точность на новых объектах. Сравнение — постоянная вероятность, равная доле положительных примеров только в тренировочной выборке.

Случайные сцены: размер, масса и трение независимо выбираются из непрерывных диапазонов; 30% объектов закреплены. Алгоритму не передаются скрытые физические параметры. Из-за слабой наблюдаемости не гарантируется, что он научится предсказывать всё по одному пробному касанию.

Запуск:

```bash
python affordance_rollouts.py --output runs/embodied
```

Стандартно выполняются 32 тренировочные и 16 тестовых физических сцены. Обученная модель и измерения находятся в каталоге `runs/embodied/`. Модель сохраняется в JSON. Не смешивайте обучающие и тестовые seed.

Важно: это адаптация **прогноза результатов толчка**, а не обучение моторного навыка и не обучение распознаванию материалов камерой. Моторика остаётся V5 reference. Один сценарий — один независимый физический эпизод для воспроизводимого обучения. Цель автономного непрерывного цикла с несколькими объектами в одной комнате проверяется отдельным сценарием.

Порог 5 см выбран как инженерный критерий заметного итогового смещения.
Начальные прогоны с прогнозом только добавочного движения дали результат хуже константного базового прогноза. Новая постановка оценивается на других случайных seed и не должна подбираться по той же тестовой выборке.
